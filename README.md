# Telegram бот знакомств (аналог «ДайВинчик»)

Готовый бот знакомств с ключевыми механиками:

- регистрация анкеты (имя, возраст, город, описание, пол, кого ищет)
- просмотр анкет по свайп-логике (❤️ / 👎)
- лайки и взаимные мэтчи
- анонимный чат между мэтчами
- просмотр/редактирование своей анкеты
- простая админ-панель через переменные окружения

> ⚠️ Это production-ready каркас с основной логикой «как у ДайВинчика». Для "полного аналога" в коммерческом смысле обычно добавляют модерацию, антиспам, ML-рекомендации, платежи, жалобы, и горизонтальное масштабирование.

## Быстрый старт

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите `BOT_TOKEN`.
2. Скопируйте `.env.example` в `.env` и заполните значения.
3. Установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

4. Запустите:

```bash
python bot.py
```

## Переменные окружения

См. `.env.example`.

## Основные команды

- `/start` — старт, регистрация, меню
- `/profile` — показать свою анкету
- `/edit` — редактировать анкету
- `/browse` — смотреть анкеты
- `/chat` — показать список мэтчей и начать чат
- `/stopchat` — выйти из текущего чата

## Структура

- `bot.py` — все хендлеры и бизнес-логика
- `db.py` — SQLite слой (анкеты, лайки, мэтчи, чат)
- `states.py` — FSM состояния
